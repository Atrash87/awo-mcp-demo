
Datathon Challenge Specification

The prototype serves as an excellent foundation for a team-based datathon challenge.

    Challenge Title: Build an AI Interface for AWO Data using MCP

  Objective:  
Extend the provided prototype so an AI assistant can answer a broader range of useful questions about AWO facilities, leveraging controlled MCP tools to ensure security and accuracy.

  Suggested Tasks:  
1.    Connect Real Data:   Connect the MCP server to a larger, more realistic processed dataset (e.g., provided by the organizers).
2.    Design Additional Tools:   Create new tools to provide valuable insights, such as:
    - Facilities by postcode.
    - Statistics and summaries by city (e.g., total capacity, service types).
    - Service distribution analysis.
    - Nearest facility based on a given address or coordinates.
3.    Improve Robustness:   Add thorough input validation and comprehensive error handling.
4.    Enhance Security:   Implement a simple but effective authentication/authorization concept.
5.    Improve User Experience:   Format the AI's responses to be more readable and user-friendly.
6.    Demonstrate the Solution:   Build a compelling demo using Claude Desktop or another MCP client.

  Deliverables:  
- Complete source code for the MCP server and client.
- Clear and thorough documentation.
- A live or recorded demonstration of the solution.

  Evaluation Criteria:  
-   Correctness:   The AI assistant accurately answers queries using the tools.
-   Code Quality:   The code is well-structured, documented, and maintainable.
-   Security:   The implementation demonstrates a strong understanding of controlled access.
-   Practical Value:   The tools provide meaningful and useful insights for AWO.
-   Documentation & Demo:   The project is clearly explained and effectively showcased.

  Expected Outcome:  
A functional, reusable MCP interface that allows AI assistants to safely and intelligently query trusted AWO data, all without bypassing or compromising the integrity of the existing data pipeline.
